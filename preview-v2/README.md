# کلمه‌ساز ۲ — پیش‌نمایش تعاملی

این پوشه یک prototype وب مستقل است و `preview/` قدیمی را دست‌نخورده نگه می‌دارد. برای جلوگیری از دو نسخهٔ متفاوت از touch engine، صفحهٔ بازی مستقیماً هندسه و ماشین حالت worklet-safe را از این فایل‌های اپ native می‌خواند:

- `../src/services/game/wheelGeometry.shared.js`
- `../src/services/game/wheelInteraction.shared.js`

## اجرا

از ریشهٔ مخزن اجرا کنید تا دادهٔ ۵۰ مرحله از `src/data/levels/levels.ts` به‌صورت خودکار برای مرورگر صادر و سپس Preview همراه مسیرهای `src/` سرو شود:

```sh
npm run preview:v2
```

سپس `/preview-v2/` را در همان origin باز کنید. در sandbox پیش‌نمایش، سرور باید روی `0.0.0.0` بماند؛ در مرورگر واقعی از `localhost` دستگاه بازدیدکننده استفاده نکنید. برای بازسازی جداگانهٔ دادهٔ مرورگر نیز `npm run preview:levels` موجود است.

## سناریوهای تعامل

- **Tap:** روی یک کاشی بزنید؛ حرف به word board افزوده می‌شود. کاشی‌های دارای نویسهٔ یکسان، شناسه‌های جدا دارند.
- **Swept pointer path:** از مرکز یک tile با حرکت سریع عبور کنید؛ ماشین حالت، segment محدود بین نمونهٔ قبلی و فعلی را با `getSegmentTileHits` بررسی می‌کند و hitها را به ترتیب `t` اعمال می‌کند.
- **Backtrack:** در تست «A → B → C → B» بازگشت به حرف قبلی، tail را حذف می‌کند؛ عبور از حروف قدیمی‌تر انتخاب را تصادفی تغییر نمی‌دهد.
- **Dead zone:** شروع drag در فضای خالی مالکیت نمی‌گیرد و فاصلهٔ میانی بین دایره‌های hit به کاشی مجاور snap نمی‌شود.
- **Cancel / multi-touch / background:** `pointercancel`، از دست رفتن capture، دومین pointer، `blur` و `visibilitychange` انتخاب را به snapshot پیش از drag برمی‌گردانند و هرگز submit نمی‌کنند.
- **Submit:** tap روی «بررسی» یا رهاکردن drag واژه را فقط یک بار validate می‌کند؛ پیام خطا علت‌محور است.
- **Repeated letters:** «حروف تکراری» را در جعبهٔ تمرین لمس باز کنید تا دو کاشی هم‌نویسه با idهای مستقل را ببینید.

دکمه‌های جعبهٔ «تمرین لمس» ماشین حالت مشترک را با سناریوهای قابل تکرار اجرا می‌کنند؛ آزمون pointer واقعی از روی wheel در مرورگر، مسیر جداگانهٔ بالا را استفاده می‌کند.

## تکمیل مرحله‌ها

- پاسخ‌ها و حروف هر مرحله از کاتالوگ واقعی `src/data/levels/levels.ts` به `levels.js` صادر می‌شوند؛ Preview پاسخ‌های مرحله‌ها را جداگانه hardcode نمی‌کند.
- پس از ثبت آخرین واژهٔ اصلی، پیام تبریک روی صفحه می‌ماند و پس از ۲٫۵ ثانیه مرحلهٔ بعد شروع می‌شود؛ تکمیل مرحلهٔ ۵۰ بازی را جمع‌بندی می‌کند و به خانه برمی‌گردد.
- پیشرفت و پاداش سکه/امتیاز در localStorage حفظ می‌شوند. تکمیل چالش روزانه فقط به خانه برمی‌گردد و شمار مرحله‌های عادی را جلو نمی‌برد.
- هنگام بازی bottom navigation پنهان است تا روی دکمهٔ ثبت واژه در viewportهای کوتاه نیفتد؛ بازگشت با دکمهٔ بالای صفحه انجام می‌شود.
