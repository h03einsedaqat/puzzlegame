## معرفی

**کلمه‌ساز** یک بازی معمایی فارسی برای اندروید است. در هر مرحله چند حرف در اختیار داری؛ با لمس یا کشیدن روی چرخ حروف واژه بساز، کلمه‌های اصلی را پیدا کن و مرحله‌های بعدی را باز کن. علاوه بر جواب‌های مرحله، واژه‌های امتیازی پنهان هم وجود دارند که از همان حروف ساخته می‌شوند.

بازی برای استفادهٔ آفلاین طراحی شده است: واژه‌نامه، مرحله‌ها، چالش‌های روزانه و پیشرفت روی دستگاه نگهداری می‌شوند؛ حساب کاربری یا اتصال به سرور برای بازی لازم نیست.

## ویژگی‌های بازی

### مرحله‌ها و واژه‌ها

- **۵۰ مرحله** در پنج جهان ده‌مرحله‌ای، با مسیر سختی از آسان تا حرفه‌ای.
- در هر مرحله یک مجموعه حرف، چند **واژهٔ اصلی** برای تکمیل مرحله و واژه‌های **امتیازی** برای کشف بیشتر وجود دارد.
- مرحلهٔ نخست آموزش تعاملی بازی است.
- واژه‌نامه شامل **۱٬۱۶۶ واژهٔ یکتای معتبر** است. مرحله‌ها از داده‌های محلی تولید و با ابزار اعتبارسنجی بررسی می‌شوند.
- بازی از حروف و واژه‌های فارسی پشتیبانی می‌کند و ورودی را برای شکل‌های مختلف حروف فارسی نرمال می‌کند.

### امتیاز و پیشرفت

امتیاز و سکهٔ پایه بر اساس تعداد حروف واژه محاسبه می‌شوند؛ ضریب سختی مرحله، واژهٔ امتیازی و کمبو هم در امتیاز نهایی اثر دارند:

| تعداد حروف | امتیاز پایه | سکهٔ پایه |
| ---------: | ----------: | --------: |
|          ۳ |          ۳۰ |         ۲ |
|          ۴ |          ۴۵ |         ۳ |
|          ۵ |          ۷۰ |         ۵ |
|          ۶ |         ۱۰۰ |         ۸ |
|          ۷ |         ۱۴۰ |        ۱۲ |
|          ۸ |         ۱۹۰ |        ۱۵ |
|          ۹ |         ۲۴۰ |        ۲۰ |

- واژه‌های امتیازی **۱٫۳۵ برابر امتیاز پایه** دارند؛ کمبو برای واژه‌های درستِ پیاپی تا چهار پله، به ازای هر پله ۶ امتیاز اضافه می‌کند.
- واژه‌ای که با راهنما آشکار شود فقط بخشی از امتیاز را می‌دهد و سکهٔ واژه ندارد.
- مرحله با یافتن همهٔ واژه‌های اصلی کامل می‌شود. **۳ ستاره** یعنی همهٔ واژه‌های اصلی، بدون راهنما، و دست‌کم نیمی از واژه‌های امتیازی؛ با یک راهنما حداکثر ۲ ستاره و با راهنماهای بیشتر ۱ ستاره می‌گیری.
- پس از تکمیل مرحله، صفحهٔ نتیجه امتیاز، سکه، ستاره‌ها و واژه‌های پیداشده را نشان می‌دهد و مرحلهٔ بعد در نقشه باز می‌شود.
- **۱۴ دستاورد** برای پیشرفت‌هایی مانند پیدا کردن واژه، تکمیل مرحله، کمبو و ادامه‌دادن چالش روزانه وجود دارد.
- صفحهٔ آمار، پیشرفت مرحله‌ها، واژه‌های پیدا‌شده، رکوردها و عملکرد چالش روزانه را نشان می‌دهد.

### سکه، قلب و راهنما

- شروع بازی با سکه و قلب انجام می‌شود؛ تلاش برای ورود به مرحله معمولاً یک قلب مصرف می‌کند. مرحلهٔ آموزشی رایگان است.
- حداکثر **۵ قلب** نگهداری می‌شود و با گذشت زمان، هر **۳۰ دقیقه** یک قلب بازمی‌گردد. با تکمیل مرحله، قلب مصرف‌شده پس داده می‌شود.
- سکه از کشف واژه و پاداش مرحله به دست می‌آید و برای راهنما یا پرکردن قلب‌ها قابل استفاده است.
- سه نوع راهنما در دسترس است: آشکارکردن یک حرف، راهنمای هوشمند و آشکارکردن واژه؛ هزینه‌ها به‌ترتیب **۱۵، ۲۵ و ۴۵ سکه** است.

### چالش روزانه

- هر روز یک پازل روزانه از مجموعهٔ **۶۰ پازل** انتخاب می‌شود؛ پازل همان روز برای همه یکسان است.
- با کامل‌کردن چالش، امتیاز و سکه می‌گیری و پاداش روزانه را دریافت می‌کنی.
- زنجیرهٔ روزانه و نقطه‌های عطف **۱، ۳، ۷، ۱۴ و ۳۰ روزه**، انگیزهٔ بازگشت منظم ایجاد می‌کنند.
- برای جلوگیری از پاداش‌های تکراری، دریافت پاداش روزانه و زمان دستگاه کنترل می‌شود.

### تجربه و دسترس‌پذیری

- رابط فارسی راست‌به‌چپ با الهام از کاغذ، چوب گردو، برنج و کاشی فیروزه‌ای؛ آیکون بازی نیز همین حال‌وهوا را با فنجان قهوه و حرف «ک» ادامه می‌دهد.
- تم **مطابق دستگاه، روشن یا تاریک**؛ انتخاب دستی در تنظیمات ذخیره می‌شود.
- تنظیم صدای بازی، لرزش و کاهش انیمیشن.
- چیدمان واکنش‌گرا، نواحی لمس مناسب و برچسب‌های دسترس‌پذیری برای اجزای تعاملی.

## چطور بازی کنیم؟

1. از صفحهٔ خانه، ادامهٔ بازی یا نقشهٔ مرحله‌ها را انتخاب کن.
2. حروف روی چرخ را لمس کن یا انگشتت را روی آن‌ها بکش تا واژه بسازی.
3. واژهٔ ساخته‌شده را با رهاکردن انگشت یا دکمهٔ ثبت بفرست؛ واژهٔ معتبرِ روی صفحه پس از مکث کوتاه هم خودکار ثبت می‌شود. اگر واژه در واژه‌نامه باشد، امتیاز و پاداشش را می‌گیری. واژهٔ درستِ تکراری دوباره امتیاز نمی‌دهد.
4. همهٔ واژه‌های اصلی مرحله را پیدا کن تا مرحله کامل شود. در زمان نیاز از راهنما استفاده کن.
5. در صفحهٔ نتیجه، ستاره‌ها و پاداش را ببین و به مرحلهٔ بعد برو، مرحله را تکرار کن یا به خانه برگرد.
6. از صفحهٔ چالش روزانه برای پازل و پاداش جداگانهٔ همان روز استفاده کن.

## معماری پروژه

ساختار کد مرز روشنی میان قوانین بازی، داده، ذخیره‌سازی و رابط کاربری دارد:

- **`src/services/game/` — منطق بازی:** اعتبارسنجی واژه، محاسبهٔ امتیاز، کمبو، ستاره و پاداش. قواعد اصلی تا حد امکان مستقل از رابط کاربری نگه داشته شده‌اند تا جداگانه آزمون‌پذیر باشند.
- **`src/data/` — محتوای محلی:** واژه‌نامه، ۵۰ مرحله، ۶۰ پازل روزانه و تعریف دستاوردها.
- **`src/services/storage/` — ذخیره‌سازی:** مخزن‌های متمرکز، مقدارهای پیش‌فرض، نسخهٔ طرح‌واره و مسیر بازیابی دادهٔ خراب.
- **`src/context/` — وضعیت برنامه:** ارائه‌دهنده‌های سرویس، تنظیمات، تم، پروفایل، پیشرفت، چالش روزانه، دستاوردها و نشست بازی.
- **`src/components/game/` و `src/components/ui/` — رابط قابل استفادهٔ مجدد:** چرخ حروف، کاشی‌ها، جایگاه واژه، راهنما، کارت‌ها، دکمه‌ها و اجزای مشترک.
- **`src/screens/` — صفحه‌های محصول:** شروع، آموزش، خانه، نقشه، بازی، نتیجه، چالش روزانه، تنظیمات، آمار، دستاوردها، درباره و حریم خصوصی.
- **`src/constants/`، `src/theme/` و `src/types/` — پیکربندی و مدل‌ها:** اقتصاد بازی، متن‌های فارسی، پالت‌ها، تایپوگرافی و نوع‌های دامنه.
- **`tools/` — ابزارهای توسعه:** تولید و بررسی مرحله‌ها، صدا، فونت و آیکون.

ذخیره‌سازی از داخل صفحه‌ها مستقیماً صدا زده نمی‌شود؛ صفحه‌ها از contextها استفاده می‌کنند و contextها با سرویس‌ها ارتباط دارند. سرویس‌های تبلیغات، تحلیل رویداد و خرید نیز پشت رابط مستقل قرار دارند تا بتوان آن‌ها را در آینده جداگانه فعال یا جایگزین کرد.

## شروع سریع

### پیش‌نیازها

- Node.js نسخهٔ **22.13 یا بالاتر**
- JDK نسخهٔ **17 یا 21**
- Android Studio و Android SDK برای اجرا یا ساخت نسخهٔ اندروید
- گوشی اندروید یا شبیه‌ساز؛ برای نصب از رایانه، Android Platform Tools (`adb`)

جزئیات نصب SDK و عیب‌یابی در [راهنمای ساخت و اجرا](docs/BUILD_AND_RUN.md) آمده است.

### نصب وابستگی‌ها و اجرای توسعه

```bash
git clone https://github.com/h03einsedaqat/puzzlegame.git
cd puzzlegame
npm ci
npm run android:preflight
npm start
```

در ترمینال دیگری، دستگاه یا شبیه‌ساز متصل باشد و اجرا کن:

```bash
npm run android
```

اگر Metro روی دستگاه فیزیکی پیدا نشد، راهنمای `adb reverse` در [BUILD_AND_RUN.md](docs/BUILD_AND_RUN.md) را دنبال کن. برای APK مستقل از Metro یا ساخت AAB، از دستورهای بخش بعد استفاده کن.

## دستورهای پرکاربرد

| دستور                              | کاربرد                                                                        |
| ---------------------------------- | ----------------------------------------------------------------------------- |
| `npm start`                        | اجرای Metro bundler                                                           |
| `npm run android`                  | ساخت و نصب نسخهٔ توسعه روی دستگاه/شبیه‌ساز                                    |
| `npm run typecheck`                | بررسی TypeScript بدون تولید فایل                                              |
| `npm run lint`                     | اجرای ESLint                                                                  |
| `npm test -- --runInBand`          | اجرای همهٔ آزمون‌ها به‌ترتیب                                                  |
| `npm run test:coverage`            | اجرای آزمون‌ها همراه گزارش پوشش                                               |
| `npm run verify`                   | اجرای typecheck، lint و آزمون‌ها                                              |
| `npm run data:check`               | اعتبارسنجی همهٔ مرحله‌ها و پازل‌های روزانه                                    |
| `npm run levels:build`             | بازتولید دادهٔ مرحله‌ها از واژه‌نامه                                          |
| `npm run sounds:build`             | بازتولید فایل‌های صوتی پروژه                                                  |
| `npm run icons:build`              | ساخت اندازه‌های اندروید و آیکون ۵۱۲ پیکسلی فروشگاه از `store/icon-source.png` |
| `npm run android:preflight`        | بررسی نسخهٔ Node، جاوا و بسته‌های SDK                                         |
| `npm run android:apk:release`      | ساخت APK انتشار                                                               |
| `npm run android:aab:release`      | ساخت Android App Bundle                                                       |
| `npm run apk:verify -- <file.apk>` | بررسی یک APK خروجی                                                            |

در نسخهٔ توسعه، Metro فایل‌های JavaScript را ارائه می‌کند؛ خروجی Release باندل را داخل APK/AAB قرار می‌دهد. پیش از انتشار عمومی، چک‌لیست [کافه‌بازار](docs/BAZAAR_RELEASE_CHECKLIST.md) را بررسی کن.

## آزمون‌ها

```bash
npm test -- --runInBand
```

**آخرین اجرای ثبت‌شده:** ۲۵ مجموعهٔ آزمون، ۳۲۴ آزمون موفق، بدون شکست.

| گروه        | تعداد مجموعه | چه چیزی را بررسی می‌کند؟                                                                             |
| ----------- | -----------: | ---------------------------------------------------------------------------------------------------- |
| Unit        |           ۱۶ | موتور بازی، اعتبارسنجی و نرمال‌سازی فارسی، امتیازدهی، قلب، ذخیره‌سازی، سرویس‌ها، چیدمان و اجزای رابط |
| Integration |            ۹ | شروع بازی، کشیدن حروف، راهنما، اقتصاد، تکمیل مرحله، تنظیمات، ماندگاری و بازیابی داده                 |
| **مجموع**   |       **۲۵** | **۳۲۴ آزمون موفق**                                                                                   |

برای اجرای جداگانهٔ هر گروه:

```bash
npx jest __tests__/unit --runInBand
npx jest __tests__/integration --runInBand
```

اعتبارسنجی داده نیز با `npm run data:check` انجام می‌شود؛ اجرای فعلی آن **۵۰ مرحله، ۶۰ پازل روزانه و ۶۰۸ جواب تعریف‌شده** را بررسی می‌کند و توزیع سختی را ۱۵ آسان، ۱۵ متوسط، ۱۰ سخت و ۱۰ حرفه‌ای گزارش می‌دهد.

> Jest ممکن است هشدارهای توسعه‌ای از React Native Gesture Handler یا محیط `act()` چاپ کند؛ این هشدارها در اجرای ثبت‌شده مانع موفقیت آزمون‌ها نشده‌اند.

```text
    ├── unit/
    └── integration/
```

## حریم خصوصی و وضعیت قابلیت‌ها

- پیشرفت و تنظیمات در حافظهٔ محلی دستگاه می‌مانند؛ برنامه برای بازی‌کردن نیاز به حساب یا سرور ندارد.
- تبلیغات، تحلیل رویداد و خرید درون‌برنامه‌ای در پیکربندی فعلی **غیرفعال** هستند.
- افکت‌های صوتی به backend اختیاری متصل‌اند؛ اگر ماژول بومی پخش صدا در محیط نصب نشده باشد، بازی به‌صورت بی‌صدا ادامه می‌دهد. لرزش و صدا از تنظیمات قابل کنترل‌اند.
- جزئیات متن حریم خصوصی در [صفحهٔ داخل برنامه](src/screens/PrivacyScreen.tsx) و فایل‌های تنظیم انتشار قرار دارد.
