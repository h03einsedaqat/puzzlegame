# کلمه‌ساز

بازی معمای کلمات فارسی برای اندروید: از کاشی‌های حروف، کلمه بساز و مرحله‌ها را باز کن.

بازی کامل آفلاین است؛ دیکشنری، مرحله‌ها، پیشرفت و چالش روزانه همه روی خودِ دستگاه
نگهداری می‌شوند و برنامه برای کار کردن به هیچ سروری نیاز ندارد.

| موضوع | مقدار |
| --- | --- |
| نام برنامه | کلمه‌ساز |
| نسخه | ۱.۰.۰ (versionCode ۱) |
| بسته | `ir.kalamesaz.game` |
| حداقل اندروید | ۷.۰ (API 24) |
| هدف | Android 16 (API 36)، compileSdk 37 |
| چارچوب | React Native 0.87.1 + TypeScript (strict) |

> وضعیت: نسخه MVP کامل است (بازی، اقتصاد، چالش روزانه، دستاوردها، تنظیمات و آزمون‌ها).
> تبلیغات و خرید درون‌برنامه‌ای عمداً غیرفعال‌اند و فقط زیرساخت آن‌ها آماده است.
> پیش از انتشار در کافه‌بازار، فهرست `docs/BAZAAR_RELEASE_CHECKLIST.md` باید کامل شود.

## چه چیزی در بازی هست

- **۵۰ مرحله دست‌ساز** با منحنی سختی کالیبره‌شده: ۱۵ آسان، ۱۵ متوسط، ۱۰ سخت، ۱۰ حرفه‌ای.
  هر مرحله یک «واژه کلیدی» دارد که از همه کاشی‌ها ساخته می‌شود و واژه‌های اصلی و
  امتیازی از همان حروف بیرون می‌آیند.
- **واژه‌نامه ۱٫۱۰۰ واژه‌ای فارسی** در ۱۷ دسته موضوعی، بدون واژه نامناسب، نام شخصی
  یا برند و بدون تکیه بر داده‌های با مجوز نامشخص.
- **اقتصاد بازی**: سکه بر پایه طول کلمه (۳→۲، ۴→۳، ۵→۵، ۶→۸)، واژه امتیازی گران‌تر،
  کمبو برای کلمه‌های پشت‌سرهم، قلب با پر شدن زمان‌محور (۵ قلب، هر ۳۰ دقیقه یک قلب) و
  بازگشت قلب پس از تکمیل مرحله؛ شکست در بازی جریمه سنگین ندارد.
- **سه لایه راهنما** (خرید را با سکه): در MVP فقط «آشکارکردن یک حرف» فعال است؛
  دو لایه دیگر در `gameConfig` تعریف شده‌اند و در نسخه‌های بعدی روشن می‌شوند.
- **چالش روزانه قطعی**: پازل هر روز از تاریخ میلادی روز مشتق می‌شود؛ همه کاربران در
  یک روز پازل یکسان می‌بینند، پاداش یک بار در روز قابل دریافت است و زنجیره روزانه
  (۱، ۳، ۷، ۱۴، ۳۰) محافظت ضد‌تقلب ساعت دارد.
- **۱۴ دستاورد** و آمار بازیکن (کلمه‌های یافته، بازی‌های تمام‌شده، بهترین کمبو).
- **تنظیمات ماندگار**: صدا، لرزش، کاهش انیمیشن، و پاک‌کردن پیشرفت.
- **صدا و لرزش**: ۹ افکت صوتی که خودِ پروژه تولید می‌کند (بدون فایل شخص ثالث) و
  الگوهای لرزش کوتاه.

## چرا این‌طور ساخته شده

- **هسته بازی، خالص و تست‌پذیر است.** منطق بازی در `src/services/game` است و هیچ
  وابستگی‌ای به React یا AsyncStorage ندارد؛ رابط کاربری فقط رندر و اتصال می‌کند.
- **همه داده‌ها محلی و نسخه‌دارند.** ذخیره‌سازی در یک لایه متمرکز
  (`src/services/storage`) با کلیدهای واحد، پوشش نسخه‌دار، مسیر مهاجرت و بازگشت به
  مقدار پیش‌فرض در صورت خراب‌بودن داده.
- **سرویس‌ها پشت واسط هستند.** صدا، لرزش، تبلیغات، تحلیل رویداد و خرید هرکدام واسط
  دارند؛ نسخه واقعی بعداً بدون تغییر در صفحه‌ها جایگزین می‌شود.
- **معماری آماده رشد است.** مرزهای `data` / `services` / `context` / `screens` طوری
  چیده شده‌اند که افزودن سرور، حساب کاربری یا محتوای فصلی، بدون بازنویسی انجام شود.

## ساختار پروژه

```
src/
  assets/        صداهای بازی و فونت وزیرمتن (+ مجوز OFL)
  components/    اجزای رابط: ui/ (۱۴ جزء پایه) و game/ (کاشی، جای خالی، سرصفحه، …)
  constants/     پیکربندی اقتصاد، کلیدهای ذخیره‌سازی، متن‌های فارسی، اطلاعات برنامه
  context/       هفت تأمین‌کننده: سرویس‌ها، تنظیمات، پروفایل، پیشرفت، چالش، دستاورد، بازی
  data/          واژه‌نامه، مرحله‌ها، پازل‌های روزانه، دستاوردها
  hooks/         وضعیت ماندگار، شمارش معکوس، کاهش انیمیشن
  navigation/    مسیرها و قرارداد پارامترها
  screens/       ۱۱ صفحه (Splash تا Privacy)
  services/      storage, game, sound, vibration, ads, analytics, purchase, clock
  theme/         رنگ، فاصله، شعاع، سایه، تایپوگرافی
  types/         مدل‌های دامنه
  utils/         نرمال‌سازی فارسی، تاریخ، تقویم جلالی، قالب‌بندی، تصادفی قطعی
tools/           ابزارهای تولید مرحله، صدا، آیکون و اعتبارسنجی داده
__tests__/       unit/ (۸ پرونده) و integration/ (۵ پرونده)
docs/            طرح پروژه، فهرست انتشار، متن فروشگاه، برنامه اسکرین‌شات، راهنمای ساخت
```

## شروع کار

نیازمندی‌ها: Node.js ۲۲.۱۳ یا بالاتر، JDK ۱۷ یا ۲۱، Android SDK با build-tools 37 و
platform 37 (راهنمای کامل در `docs/BUILD_AND_RUN.md`).

```bash
npm install                # نصب وابستگی‌ها
npm run fonts:link         # کپی فونت وزیرمتن به assets اندروید (در بیلد هم خودکار است)
npm start                  # Metro
npm run android            # نصب و اجرا روی دستگاه/شبیه‌ساز
```

ساخت فایل نصبی:

```bash
npm run android:apk:release   # خروجی: android/app/build/outputs/apk/release/app-release.apk
npm run android:aab:release   # خروجی AAB برای کافه‌بازار
```

## آزمون‌ها

```bash
npx jest __tests__/unit            # واحد: نرمال‌سازی، واژه‌نامه، موتور بازی، ذخیره‌سازی، سرویس‌ها، اجزا
npx jest __tests__/integration     # یکپارچه: چرخه بازی، ماندگاری، اقتصاد قلب، تنظیمات، بازیابی داده خراب
```

آزمون‌های یکپارچه همان کارهایی را انجام می‌دهند که کاربر انجام می‌دهد: از آموزش
آغازین می‌گذرند، کاشی‌ها را می‌زنند، واژه ثبت می‌کنند، صفحه نتیجه را می‌بینند و
پیشرفت را از حافظه دستگاه می‌خوانند. «بستن و باز کردن برنامه» با پاک‌کردن درخت رابط
و سوارکردن دوباره برنامه شبیه‌سازی می‌شود.

## داده‌ها

مرحله‌ها از واژه‌نامه تولید می‌شوند. اگر واژه‌نامه یا مدل سختی را عوض کردید:

```bash
npm run levels:build     # بازتولید مرحله‌ها (آستانه‌های سختی را هم گزارش می‌دهد)
npm run levels:check     # اعتبارسنجی خروجی
npm test                 # آزمون‌ها روی داده تازه
```

منحنی سختی باید همان ۱۵/۱۵/۱۰/۱۰ بماند؛ اگر آستانه‌های `DIFFICULTY_THRESHOLDS`
نیاز به کالیبراسیون داشته باشند، ابزار `levels:build` هشدار می‌دهد و اعداد پیشنهادی
را چاپ می‌کند.

## مجوزها و اعتبارها

- فونت [وزیرمتن](https://github.com/rastikerdar/vazirmatn) با مجوز SIL OFL 1.1
  (`src/assets/fonts/OFL.txt`).
- افکت‌های صوتی به‌صورت برنامه‌نویسی‌شده در `tools/build-sounds.mts` تولید می‌شوند؛
  هیچ فایل صوتی شخص ثالثی در پروژه نیست.
- آیکون از گلیف «ک» فونت وزیرمتن و رنگ‌های برند بازی ساخته می‌شود (`tools/build-icons.mts`).

## حریم خصوصی

بازی هیچ داده‌ای را از دستگاه بیرون نمی‌فرستد. هیچ SDK تبلیغاتی، تحلیلی یا خریدی در
نسخه فعلی فعال نیست و بازی به مجوز اینترنت نیاز ندارد. متن کامل در صفحه «حریم
خصوصی» داخل برنامه و در `src/screens/PrivacyScreen.tsx` است.
