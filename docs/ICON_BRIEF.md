# خلاصهٔ طراحی آیکون — کلمه‌ساز

## جهت هنری

آیکون تازه حال‌وهوای یک کافه‌خانهٔ ایرانیِ امروزی را به هویت بازی می‌آورد: فنجان قهوهٔ ساده، کاشی فیروزه‌ای با حرف «ک»، رنگ‌های کاغذی و برنجی، و زمینهٔ گرمِ گردویی. نقش‌مایهٔ ایرانی فقط در بافت و قاب مرکزی دیده می‌شود تا آیکون در اندازهٔ کوچک هم واضح بماند.

این طرح بین سنت و مدرنیته تعادل دارد؛ از جزئیات دست‌ساز و رنگ‌های ایرانی الهام می‌گیرد اما نشان مرکزی ساده و قابل‌تشخیص است. متن دیگری جز حرف داخل نشان نیست.

## فایل مرجع و خروجی‌ها

- `store/icon-source.png` — تصویر مرجع مربعی و باکیفیت؛ منبع ساخت همهٔ اندازه‌ها.
- `store/icon-512.png` — خروجی ۵۱۲×۵۱۲ برای فروشگاه.
- `preview/icon-preview.png` — نسخهٔ ۵۱۲×۵۱۲ برای بازبینی سریع.
- `preview/persian-cafe-icon.png` — تصویر اصلی انتخاب‌شده در کیفیت کامل.
- `android/app/src/main/res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png` — آیکون اجرای برنامه.
- `android/app/src/main/res/mipmap-*/ic_launcher_round.png` — خروجی با ماسک دایره‌ای برای لانچرهای قدیمی.
- فایل‌های `ic_launcher_background.png` و `ic_launcher_foreground.png` همراه با XMLهای `mipmap-anydpi-v26` برای آیکون تطبیقی اندروید.

ساخت مجدد تمام خروجی‌ها:

```bash
npm run icons:build
```

فرمان قدیمی `npm run icons:mascot` هم برای سازگاری باقی مانده و همان تصویر مرجع جدید را می‌سازد.
