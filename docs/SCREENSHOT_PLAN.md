## چطور گرفته می‌شوند

روی دستگاه واقعی (ترجیحاً صفحه‌ای با نسبت ۱۹.۵:۹ یا ۲۰:۹):

```bash
# ۱) نسخه انتشار را نصب کن (نوار وضعیت و کادر اشکال‌زدایی دیده نشود)
npm run android:apk:release
adb install -r android/app/build/outputs/apk/release/app-release.apk

# ۲) گوشی را آماده کن
#    - حالت پرواز روشن (برای نمایش آفلاین‌بودن)
#    - روشنایی صفحه روی حدود ۷۰٪
#    - پاک‌کردن برنامه از فهرست برنامه‌های اخیر، تا از هر صفحه تازه شروع شود
#    - اگر خواستی، از یک حساب کاربری/دستگاه تازه برای اسکرین‌شات‌های ۵ و ۶ استفاده کن

# ۳) گرفتن تصویر
adb exec-out screencap -p > store/screenshots/01-game.png
```

میان‌بر مک: هنگام باز بودن صفحه بازی، دکمه پاور + کم‌کردن صدا.

## قواعد کیفیت

- **همه تصویرها از یک دستگاه و یک تم**؛ نه قاطی‌کردن گوشی‌های مختلف.
- هیچ پیام سیستمی، اعلان، ساعت عجیب، باتری ۳٪ یا نام شخصی روی نوار وضعیت نباشد.
- نوار وضعیت تمیز: اعلان‌ها پاک، حالت پرواز روشن (پیام «آفلاین» با تصویر هم‌خوان است).
- متن‌ها باید خوانا باشند؛ اگر لازم شد، فقط بزرگ‌نمایی نرم بدون تغییر محتوا مجاز است.
- هیچ کادر یا فلش اضافه و متن انگلیسی روی تصویر نباشد.
- خروجی PNG، عرض حداقل ۱۰۸۰ پیکسل، بدون فشرده‌سازی محسوس.
- پیش از بارگذاری، تصویرها با نام مرتب ذخیره شوند: `01-game.png` تا `08-result.png`
  در پوشه `store/screenshots/`.

## چه چیزی در تصویرها نباشد

- صفحه سفید، صفحه بارگذاری یا پیام خطا.
- مرحله‌ای که راهنما آن را نیمه‌آشکار کرده (کلمه نیمه‌تمام، حس ناتمام می‌دهد).
- مراحل پایان بازی با کلمه‌های نادر یا نامفهوم؛ تصویر اول باید یک مرحله آسان و
  آشنا باشد.
- هر متن یا عددی که با وضعیت واقعی بازی هم‌خوانی ندارد.
